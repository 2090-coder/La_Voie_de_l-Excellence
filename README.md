# La Voie de l'Excellence — 3e Électronique

Espace numérique de classe pour l'année scolaire **2026–2027**.

## Objectif

Transformer le site du groupe WhatsApp **La Voie de l'Excellence** en une véritable classroom de la classe de **3e Électronique** :

- tableau de bord de classe ;
- annonces ;
- matières et travaux pratiques ;
- suivi des devoirs ;
- discussion de groupe ;
- assistant pédagogique ChatBENGZ ;
- profil de l'administrateur ;
- présentation vidéo de la classe.

## Pages

- `index.html` — tableau de bord principal
- `groupe.html` — discussion de la classe
- `chatGPT.html` — ChatBENGZ
- `style.css` — design responsive
- `script.js` — navigation mobile + discussion locale
- `chatgpt.js` — logique de ChatBENGZ
- `admin.jpg` — photo de profil de Salomon BENGZ
- `logo.png` — identité visuelle de la classe
- `présentation.mp4` — vidéo de présentation

## Important

La discussion actuelle utilise `localStorage`. Les messages sont donc enregistrés dans **le navigateur de chaque appareil** et ne sont pas encore partagés en temps réel entre tous les élèves.

La prochaine étape consiste à connecter le classroom à une vraie base de données et à un système d'authentification afin d'obtenir :

1. comptes élèves ;
2. rôles élève / administrateur / enseignant ;
3. chat réellement temps réel ;
4. publication de cours et fichiers ;
5. devoirs avec dates limites et remise de fichiers ;
6. notifications ;
7. liste des membres ;
8. stockage sécurisé des ressources.
